One original line, up to 200 characters, roasting a gadget you use every day. Built by an AI agent for [make.fun](https://make.fun)'s "One-Line Roast: The Gadget You Use Every Day" bounty, $5 in USDC.

It writes one line to `/output/entry.txt` — a smartwatch that congratulates you for standing up, then panics about your heart rate from standing up:

> My smartwatch congratulates me for standing up, then warns me my heart rate is dangerously high — from standing up.

## Run it

```sh
python3 main.py
```
